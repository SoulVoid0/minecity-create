# MineColonies: Modern City — Plan

Target: Minecraft 1.21.1, NeoForge 21.1.x. Mod id `moderncity`.

## 1. How it is built

A MineColonies "style" is a Structurize blueprint pack (`pack.json` + `.blueprint` files, levels 1–5 per hut).
Packs inside a mod jar under `blueprints/<modid>/<pack>/` are discovered automatically, so this mod is:

| Layer | What | Needs code? |
|---|---|---|
| A. Style pack | Modern versions of every vanilla MineColonies hut (townhall, residence, warehouse, miner, farmer, barracks, etc.) | No |
| B. Decoration / infrastructure blueprints | Roads, intersections, street lights, power lines, bridges, rail stations, train depots, power plants, skyscraper shells | No (placed with Build Tool as "decorations", built by Builder) |
| C. Functional machinery inside blueprints | Create contraptions (elevator pulley elevators, mechanical farms, drills), AE2 networks, CC&A / Diesel / Nuclear generators, TFMG factories, S&R trains | No — blueprints carry block entities; Builder places them, player wires power/controllers once |
| D. Code addon (Phase 3) | New hut types MineColonies lacks: Power Plant (citizen operates generators/fuel), Data Center (citizen manages AE2 crafting), Train Station (courier via S&R trains), Shopping Center (market) | Yes, MineColonies API (ModBuildings / ModJobs registries) |

## 3. Phases

1. **Skeleton**: mod project, pack.json, category folders, dependency list. Done.
2. **Blueprints** (generated by `tools/blueprintgen`, format verified against Structurize `version/1.21` source). 2a done: town hall, builder, residence, warehouse, courier, miner + shafts, roads, lights, power pole, substation, in both the full and Lite packs. Remaining order: Town Hall → Builder → Residence → Warehouse → Courier → roads/lights → farms → mine → factories → military → power/data/trains/bridges/skyscrapers.
3. **Code huts**: Power Plant, Data Center, Train Station, Shopping Center with jobs, GUIs, research gates.
4. **Polish**: icons, lang, guide book entries, balancing, release.

## 4. Open risks

- Generated blueprints are validated structurally but not yet placed in a real world; first in-game test should be town hall → builder → residence.
- Macaw's and Chipped blocks are not used yet: their 1.21.1 block ids still need verifying (closed source / no lang dump available).
- Mod ids marked "verify" below must be checked in a dev instance (`/neoforge mods` or the log line this mod prints at startup).
- Builder can place Create/AE2 block entities but not connect kinetic networks, AE2 channels, or train schedules automatically; a one-time player setup per building is expected.
