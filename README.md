# MineColonies: Modern City

A modern-city style pack and addon for **MineColonies 1.21.1 (NeoForge)**: glass office towers, apartment
blocks with working Create elevators, steel factories, AE2 data rooms, a power grid, roads and street lights.

## Two packs, maximum compatibility
| Pack | Needs | What you get |
|---|---|---|
| **Modern City** | MineColonies + Create 6 + AE2 + Create Crafts & Additions | Full version with functional machinery |
| **Modern City Lite** | MineColonies only | Same buildings, every modded block swapped for a vanilla look-alike |

Only MineColonies/Structurize are hard dependencies; Structurize hides a pack whose mods are missing,
so the Lite pack is always there and the full pack appears automatically when its mods are installed.

## What's in it so far
Town hall, builder, residence (apartments, 2→10 floors), warehouse, courier, miner + all miner shaft
nodes (levels 1–5 each), modern road tiles (straight, crosswalk, corner, T, intersection, dead end),
street lights, power line pole and substation. See `docs/BLUEPRINTS.md` and `docs/PLAN.md`.

## Building
```
pip install nbtlib pillow
python3 tools/blueprintgen/gen.py --check   # regenerate + validate the blueprints
./gradlew build                             # jar in build/libs
```
Blueprints are generated by code in `tools/blueprintgen/`; edit the generator, not the `.blueprint` files.
Every non-vanilla block id is checked against the mod's 1.21.1 source (`tools/blueprintgen/ids/`) and
needs a vanilla fallback in `compat.py`, so neither pack can silently lose blocks.

## One-time setup in game
Create elevators need power (CC&A electric motor next to the pulley), super glue on the car, then a
right-click on the pulley. Power poles need wire between connectors.
